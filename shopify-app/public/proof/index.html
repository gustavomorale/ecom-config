Proof of resolution: requirement 2.1.3

App: CraftFrame Bundle Quiz (client ID a1b72ae7…). Date: 24 September 2026.

Issue reported: during installation the embedded route returned HTTP 500 ("Application Error").

Cause: the app called the Billing API (appSubscriptionCreate) on first load. The app is on Shopify App Pricing, where Shopify creates the subscription from the listing's plan, so the API refused the call and the loader threw.

Fix (deployed 24 September 2026): the app no longer creates charges. On load it checks for an active subscription; when there is none it sends the merchant to Shopify's hosted plan page (/charges/bundle-configurator-8/pricing_plans). If that check ever fails, the app still renders with a notice. No 500 is possible from billing.

Verification below: fresh install on the development store craftframe-bundle-quiz-demo after uninstalling. Step 1 is Shopify's plan page reached from the app, step 2 the approval, step 3 the app interface rendered.
